# Premium Apple Products Website Design Prompt

## Design Objective

Create a **premium, modern mobile-first e-commerce website for Apple products**, inspired by the design philosophy of Apple, high-end fashion brands, and modern luxury technology websites.

The design should feel **minimal, cinematic, elegant, sophisticated, and extremely polished**. It should not be a direct copy of Apple's website. Instead, take inspiration from Apple's simplicity, premium product presentation, typography, whitespace, smooth visual hierarchy, and product-focused storytelling, then create a **distinctive original experience**.

The website should immediately communicate:

> **Premium technology. Beautifully presented. Effortlessly simple.**

---

## Visual Direction

### Overall Style

* Premium Apple-inspired aesthetic
* Minimalist luxury
* Clean editorial layouts
* Large product photography
* Generous whitespace
* Sophisticated typography
* Subtle glassmorphism where appropriate
* Smooth rounded corners
* Soft shadows
* High-quality product cards
* Cinematic product sections
* Strong visual hierarchy
* Extremely polished mobile experience
* Avoid clutter and unnecessary UI elements

Think:

**Apple × Luxury Fashion × Modern SaaS × Premium E-commerce**

The result should feel like a website for a **high-end technology boutique**, not a generic electronics store.

---

# Mobile-First Experience

Design primarily for mobile screens around:

* 390 × 844
* 393 × 852
* 430 × 932

The interface should feel native to a modern iPhone.

Use:

* Large touch targets
* Bottom navigation where appropriate
* Smooth horizontal product carousels
* Sticky purchase actions
* Swipeable galleries
* Full-width product imagery
* Comfortable spacing
* Clear typography
* Minimal navigation

The mobile layout must feel intentional rather than simply being a desktop website compressed into a phone screen.

---

# Color System

Use a sophisticated neutral palette.

### Primary

* Pure white: `#FFFFFF`
* Soft white: `#F7F7F5`
* Deep black: `#0B0B0C`
* Charcoal: `#1D1D1F`
* Soft gray: `#6E6E73`

### Accent

Use extremely subtle premium accents such as:

* Cool silver
* Titanium gray
* Deep graphite
* Soft blue
* Very subtle electric blue

Avoid excessive bright colors.

The interface should predominantly feel **black, white, silver, and neutral**.

---

# Typography

Use a modern Apple-like sans-serif aesthetic.

Recommended hierarchy:

### Hero

Large, bold, elegant typography.

Example:

**Meet the new generation.**

### Supporting text

Clean, lightweight typography with generous line-height.

Example:

**Powerful performance. Refined design. Built for everything you do.**

### Product names

Large but restrained.

Example:

**iPhone 17 Pro**

### Pricing

Clear and visually prominent without feeling aggressive.

Use typography with:

* Large headings
* Medium-weight product names
* Light supporting text
* Strong numerical pricing
* Tight but readable letter spacing

---

# Important Design Rules

### DO

* Create an original Apple-inspired visual language
* Prioritize product photography
* Use generous whitespace
* Keep layouts extremely clean
* Create strong visual hierarchy
* Use premium typography
* Make every section feel intentional
* Make mobile interactions feel native
* Use subtle motion
* Maintain consistent spacing
* Make CTAs obvious but elegant

### DO NOT

* Copy Apple's website exactly
* Reproduce Apple's page structure pixel-for-pixel
* Use Apple's proprietary marketing copy
* Create a generic electronics marketplace
* Overuse gradients
* Use excessive glassmorphism
* Use excessive animations
* Crowd the interface
* Use cheap-looking shadows
* Use too many colors
* Add unnecessary sections
